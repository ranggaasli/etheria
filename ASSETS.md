# Original asset provenance

All maps, terrain textures, architecture, trees, farm plots, furniture, avatars,
monsters, and gameplay effects are generated from original drawing routines in
`client/art.ts` and `client/game.ts`. No downloaded game graphics or audio are used.
Effects use original oscillator tones. Fonts are device-provided Georgia and Segoe
UI with system fallbacks; no font binaries are redistributed. Text symbols and
emoji use the device's font renderer. All lore and Indonesian dialogue are original.

The project source and original generated art are provided under MIT (LICENSE).
Third-party software retains its own licenses in the installed npm packages.
Exact dependency versions are recorded in package-lock.json.
